# Brand assets

Both logos have a **transparent background**.

| File | Use |
|---|---|
| `logo-dark.png` | White ink — dark backgrounds. The README serves this one on GitHub's dark theme. 1200×351. |
| `logo-light.png` | Navy ink — light backgrounds. The README serves this one on GitHub's light theme, and as the fallback for renderers without theme switching. 1200×351. |

Both are derived from one source, cropped to the mark with 5 % padding, exported at 2× the README display width, and palette-quantized (≈ 13 KB each). The blue `>` accent is kept in both; the dark variant only turns the navy ink white.
